Architecture

Browser │ ├─► CloudFront ──► S3 (React UI static files) │ └─► AgentCore Runtime ──► Express + Strands Agent (:8080) │ ├─► Amazon Bedrock (Claude) ├─► CloudWatch Logs ├─► CloudWatch Alarms / ECS ├─► SNS (escalation) └─► Runbooks (markdown in container)

Required Assessment needs AgentCore Runtime + Strands. Creating a new IAM user is NOT required.

Step 0 — Run locally first

Terminal

cd backend && npm install && npm run dev    # http://localhost:3001
cd frontend && npm install && npm run dev   # http://localhost:5173
Open http://localhost:5173 → report an incident → you should see tool evidence (CloudWatch, Runbook, SNS) in the chat.

Step 1 — AWS resources (Console clicks)

1A — Bedrock model access Console

  1. AWS Console → search Amazon Bedrock
  2. Region: US East (N. Virginia)
  3. Left → Model access → Enable Claude Sonnet
  4. Wait for status: Access granted

1B — CloudWatch log group Console

  1. Search → CloudWatch → Log groups → Create
  2. Name: /devops/incident-demo

1C — SNS topic Console

  1. Search → SNS → Topics → Create topic
  2. Name: devops-incident-escalation
  3. Create subscription → Protocol: Email → your email
  4. Confirm subscription from inbox

Step 2 — Deploy backend (AgentCore + ECR)

2A — Create ECR repository Console

  1. Search → ECR → Repositories → Create
  2. Name: devops-incident-agent
  3. Copy URI: 148761674610.dkr.ecr.us-east-1.amazonaws.com/devops-incident-agent

2B — Build & push Docker image Terminal

cd backend

aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin \
  148761674610.dkr.ecr.us-east-1.amazonaws.com

docker build --platform linux/arm64 -t devops-incident-agent .

docker tag devops-incident-agent:latest \
  148761674610.dkr.ecr.us-east-1.amazonaws.com/devops-incident-agent:latest

docker push \
  148761674610.dkr.ecr.us-east-1.amazonaws.com/devops-incident-agent:latest

2C — Create AgentCore Runtime Console

  1. Search → Amazon Bedrock
  2. Left → AgentCore → Runtimes → Create runtime
  3. Artifact: Container
  4. Container URI: 148761674610.dkr.ecr.us-east-1.amazonaws.com/devops-incident-agent:latest
  5. Port: 8080 · Network: Public · Protocol: HTTP
  6. IAM Role: click Create and use a new service role (easiest)
  7. Add environment variables (see table below)
  8. Create → wait until Active
  9. Copy the Runtime endpoint URL

Step 3 — Deploy frontend (S3 + CloudFront)

3A — Build React app Terminal

cd frontend
echo "VITE_API_URL=https://YOUR-RUNTIME-URL-HERE" > .env.production
npm run build

3B — S3 bucket Console

  1. Search → S3 → Create bucket
  2. Name: devops-incident-ui-148761674610 (unique globally)
  3. Region: us-east-1
  4. Upload all files from frontend/dist/

3C — CloudFront Console

  1. Search → CloudFront → Create distribution
  2. Origin: your S3 bucket · OAC enabled
  3. Default root object: index.html
  4. Error pages: 403 and 404 → redirect to /index.html with 200
  5. Copy CloudFront URL: https://dxxxx.cloudfront.net

3D — Update CORS on backend

AgentCore Runtime → Edit → set CORS_ORIGIN to your CloudFront URL (no trailing slash).
